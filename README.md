# Посылки: сканер приёмки (веб-версия для iPhone)

Камера читает штрихкод коробки, приложение сверяет трек со списком из Apple Notes и отмечает «Приехал».
Зелёный экран — есть в списке, жёлтый — уже сканировали, красный — нет в списке. Работает без интернета, данные хранятся только в телефоне.

- `site/` — само приложение (без сборки: HTML, CSS, модули JS). Его и выкладываем.
- `site/vendor/` — библиотеки, копируются командой `npm run vendor`: распознавание zxing-wasm 3.1.6,
  Excel write-excel-file 4.1.1, PDF pdfmake 0.3.12 и шрифт Roboto (кириллица). Excel и PDF грузятся при первом нажатии.
- `tests/` — проверки разбора заметки, сверки и фильтра кадров: `npm test`.
- `npm run serve` — открыть на компьютере: http://localhost:5180 (камеры там нет, работает «Из фото»).
- `.github/workflows/pages.yml` — после отправки в `main` тесты и выкладка на GitHub Pages.

Главные файлы: `src/parse.js` (разбор заметки), `src/match.js` (сверка), `src/scanfilter.js` (когда показывать результат),
`src/store.js` (данные: закупки, архив, резервная копия), `src/report.js` (отчёт: текст, Excel, PDF),
`src/files.js` (файлы и «Поделиться»), `src/scanner.js` (камера), `src/app.js` (экраны), `sw.js` (работа без интернета).

Закупки: каждая заметка — отдельная закупка. Завершённая уходит в архив: сканер её не сверяет, на главном она не считается.
Данные — один объект в localStorage `parcel-scanner:v1`; резервная копия — этот объект в файле `posylki-kopiya-<дата>.json`.
Новый файл в `site/` надо добавить в список `FILES` в `sw.js`, иначе он не будет работать без интернета.
