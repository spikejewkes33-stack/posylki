# Посылки: сканер приёмки (веб-версия для iPhone)

Камера читает штрихкод коробки, приложение сверяет трек со списком из Apple Notes и отмечает «Приехал».
Зелёный экран — есть в списке, жёлтый — уже сканировали, красный — нет в списке. Работает без интернета, данные хранятся только в телефоне.

- `site/` — само приложение (без сборки: HTML, CSS, модули JS). Его и выкладываем.
- `site/vendor/` — библиотека распознавания zxing-wasm 3.1.6, копируется командой `npm run vendor`.
- `tests/` — проверки разбора заметки, сверки и фильтра кадров: `npm test`.
- `npm run serve` — открыть на компьютере: http://localhost:5180 (камеры там нет, работает «Из фото»).
- `.github/workflows/pages.yml` — после отправки в `main` тесты и выкладка на GitHub Pages.

Главные файлы: `src/parse.js` (разбор заметки), `src/match.js` (сверка), `src/scanfilter.js` (когда показывать результат),
`src/store.js` (данные), `src/scanner.js` (камера), `src/app.js` (экраны), `sw.js` (работа без интернета).
